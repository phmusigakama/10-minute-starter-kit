# 10-Minute Starter Kit: ตัวเสริม

โฟลเดอร์ต้องมี `index.html` (ไฟล์หลัก) อยู่ข้างกับ `server.py`

## รันในเครื่อง

    python server.py                          # เปิด http://localhost:8000

เสร็จแล้ว ไม่ต้องตั้งค่าอะไรในหน้าเว็บ — `server.py` อ่านคีย์ OpenRouter จากไฟล์ `.env`
(ที่มาพร้อมกันอยู่แล้ว) แล้วใช้คีย์นั้นกับทุกคำขอโดยอัตโนมัติ

ไม่ต้อง pip install อะไร (ใช้ Python 3.9+ ไลบรารีมาตรฐานเท่านั้น)

ถ้าจะใช้คีย์ของตัวเอง ให้แก้ไฟล์ `.env`:

    OPENROUTER_API_KEY=sk-or-v1-...

## ปล่อยสู่สาธารณะ

ใช้ host ที่รัน Python ได้ (Render, Railway, Fly.io ฯลฯ) ตั้ง start command เป็น `python server.py`
(มี `Procfile` ให้แล้ว) และใส่ `OPENROUTER_API_KEY` ใน environment variables ของ host
อย่าใส่ key ลงใน index.html และอย่า commit ไฟล์ `.env`

## AI ทำงานอย่างไร

Step 2 (จัดระเบียบความคิด) และ Step 3 (ร่างไอเดีย) จะส่งข้อความไปที่ OpenRouter
`https://openrouter.ai/api/v1/chat/completions` แล้วเอาผลลัพธ์แบบ JSON กลับมา

- โมเดลไล่ลำดับ: `google/gemma-4-26b-a4b-it:free` -> `google/gemma-4-26b-a4b-it` -> `google/gemma-3-27b-it`
  ถ้าโมเดลแรกติด rate limit (429) ระบบจะข้ามไปตัวถัดไปให้อัตโนมัติ และข้ามตัวที่ติดลิมิตไป 10 นาที
- ถ้า AI ล่มหรือช้าเกินไป หน้าเว็บจะใช้ตัวสำรอง (ตัดข้อความตามช่องว่าง + ร่างจากแม่แบบ) โดยไม่พัง flow
- ป้ายสถานะมุมขวาบนของหน้าเว็บจะบอกว่า "AI พร้อมใช้งาน" หรือ "AI ใช้ตัวสำรอง"
- หน้าเว็บไม่มีให้กรอก API key — คีย์อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น

## ตัวแปรเสริม

- `OPENROUTER_API_KEY` คีย์ OpenRouter (จำเป็น) — อ่านจาก env หรือไฟล์ `.env`
- `MODEL` โมเดลที่ให้ลองก่อน (ค่าเริ่มต้น `google/gemma-4-26b-a4b-it:free`)
- `MODELS` รายการโมเดลไล่ลำดับ คั่นด้วยจุลภาค (ค่าเริ่มต้นดูด้านบน)
- `RATE_LIMIT_PER_HOUR` จำนวนครั้งต่อ IP ต่อชั่วโมง (ค่าเริ่มต้น 30)
- `DAILY_LIMIT` จำนวนครั้งรวมต่อวัน (ค่าเริ่มต้น 300)
- `AI_TIMEOUT` เวลารอสูงสุดต่อคำขอ (วินาที, ค่าเริ่มต้น 45)
- `MAX_TOKENS` ความยาวคำตอบสูงสุด (ค่าเริ่มต้น 1400)
- `PORT` พอร์ต (ค่าเริ่มต้น 8000)

## การพูดด้วยเสียง (Voice Input)

ปุ่ม "กดเพื่อพูด" ใช้ Web Speech API ของเบราว์เซอร์

- รองรับ: Chrome, Edge, Safari (ทั้งมือถือและคอมพิวเตอร์) — Firefox ยังไม่รองรับ
- ต้องเปิดผ่าน `https://` หรือ `localhost` เท่านั้น
- ถ้าใช้ไม่ได้ ปุ่มจะถูกปิดใช้งานพร้อมข้อความบอกเหตุผล

## หมายเหตุเรื่องข้อมูลส่วนตัว

ข้อความที่ผู้ใช้พิมพ์จะถูกส่งไปประมวลผลที่ OpenRouter เพื่อจัดระเบียบและร่างไอเดีย
ควรแจ้งผู้ใช้ให้ทราบในหน้าเว็บหรือนโยบายความเป็นส่วนตัวของคุณ
